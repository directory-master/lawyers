## ✅ Shipped so far (v0.1 → v0.35, Jun 2026)

Static-first directory of **7,624 GA listings** (6,305 with photos, 276 city
stores), generated by [scripts/generate-pages.mjs](scripts/generate-pages.mjs)
into 1,782 clean-URL pages (1,083 indexable): city, county, zip, practice area,
city×area, `/directory/`, `/areas/`, `/firms/`, `/attorneys/`, home, search /
saved / visited, pricing / privacy / terms, `404.html`, `sitemap.xml`,
`robots.txt`, GSC verification file. Bing + Google importers with a shared
ingest gate, cross-source firm merge, auto-prune. Tier-gated card + in-page
profile modal (per-lawyer pages were removed Jun 20), save/visited, near-me →
city, "Show more" pagination, FAQ + JSON-LD on every page, PWA (manifest, SVG
icon, versioned service worker, install button), a11y pass, oxblood/gilt legal
design. Full history is in `git log`.
